**ИТД** — молодежная соц сеть ильи новки и т.д.. топ место для молодеждных крутых хайповых зумеров и миллениалов!!

Эта организация и репозитории в ней **не являются официальными.** Всё, что есть здесь — создано комьюнити, от фанатов и энтузиастов для всех желающих. Главная цель проекта — помочь площадке в развитии.
